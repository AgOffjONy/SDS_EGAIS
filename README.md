# StoreScanner - Приложение для сканирования сети магазинов

## Описание
Приложение для сканирования внутренней сети предприятия, проверки доступности магазинов через пинг основного микротика и поиска компьютеров с именем EGAIS-DEB или EGIAS-DEB.

## Требования
- .NET 8.0 Windows
- Visual Studio 2022
- Права администратора для ICMP ping
- Доступ к внутренней сети предприятия

## Логика IP адресов микротиков

### Магазины до 200:
- Формат: `192.168.{номер}.81`
- Пример: магазин №90 -> `192.168.90.81`

### Магазины после 200:
- Подсети: 10.102.x.x, 10.103.x.x, 10.104.x.x, 10.105.x.x
- Формат: `10.{102+subnet}.{offset}.1`
- Пример: магазин №225 -> `10.102.25.1` (225-200=25)

## Функционал

### Ручное управление
- **Добавление магазина**: № магазина, название, регион, город, формат (Хороший, Командор, Аллея)
- **Добавление компьютера**: выбор магазина из списка, имя компьютера
- **Фильтры**: по регионам, городам, форматам магазинов

### Автоматическое сканирование
1. Проверка доступности микротика магазина (ping)
2. Если магазин доступен - сканирование подсети на наличие компьютеров с именами:
   - EGAIS-DEB
   - EGIAS-DEB
3. Для найденных компьютеров:
   - Проверка доступности (ping)
   - Проверка УТМ (http://ip:8080/app)

### Проверка УТМ
- Парсинг страницы http://ip-компьютера:8080/app
- Поиск блока `<div class="ng-star-inserted">` с 8 элементами `<mat-icon>`
- Если все 8 иконок имеют значение "check" → **"УТМ доступен"**
- Если есть иконки со значением "clear" → выводятся ошибки из блоков `<div class="ci-utm-info-list-item-text">`

## Интерфейс
- **Дерево магазинов**: отображение в формате "Название магазина - IP микротика (статус)"
- **Вложенный список компьютеров**: имя, IP, статус доступности, статус УТМ, ошибки

```bash
dotnet restore
dotnet build
```

## Запуск
```bash
dotnet run
```

## Примечания
- Данные сохраняются в файл `stores.json` в директории приложения
- Сканирование может занять время в зависимости от количества магазинов
- Требуется сетевой доступ к подсетям магазинов
